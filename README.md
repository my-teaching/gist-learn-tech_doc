# СРС: техническая документация в IT

## Что нужно сделать

1. Изучите теоретическую базу по теме **«Техническая документация программ и автоматизированных систем»**.
2. Просмотрите приложенные учебные примеры:
   - ТЗ на программу CampusDesk Web;
   - ТЗ на АС CampusDesk;
   - ПМИ CampusDesk Web;
   - руководство оператора CampusDesk;
   - примеры современной IT-документации.
3. При необходимости используйте презентацию **«Техническая документация.»**.
4. Ответьте на 5 вопросов ниже.

## Вопросы

1. Что такое CampusDesk в этой методичке и чем CampusDesk Web отличается от АС CampusDesk?
2. Что означает обозначение `REQ-FUNC-03`? Является ли такая система обозначений обязательным требованием ГОСТ?
3. Для чего нужно техническое задание (ТЗ)? Почему фраза «система должна работать быстро» является слабым требованием?
4. Что такое ПМИ и что означает результат `PASS` при выполнении теста?
5. Назовите любые два из пяти приложенных учебных документов и кратко объясните назначение каждого.

## Формат сдачи

Отправьте **один файл DOCX или PDF** с нумерованными ответами **1–5**.

Ответы должны быть краткими: обычно достаточно **1–3 предложений** на вопрос.  
Переписывать условия вопросов и теоретическую часть не требуется.

Рекомендуемое имя файла:

`Фамилия_Группа_СРС_Техническая_документация.docx`

## Оценивание

- 5 корректных ответов — **5**
- 4 корректных ответа — **4**
- 3 корректных ответа — **3**
- 0–2 корректных ответа — **доработка**
